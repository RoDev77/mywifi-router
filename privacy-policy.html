Kebijakan Privasi

Kami menghargai privasimu. Halaman ini menjelaskan data apa yang kami kumpulkan, bagaimana kami menggunakannya, dan pilihan yang kamu miliki.

1. Data yang Kami Kumpulkan

  • Nomor WhatsApp — dipakai untuk mengirim SSID, password WiFi, dan informasi transaksi.
  • Detail transaksi — durasi sewa, jumlah pembayaran, ID transaksi, status, dan waktu pembayaran.
  • Data teknis — informasi perangkat dan browser yang dikirim otomatis oleh browser saat kamu mengunjungi situs.

Kami tidak meminta nama lengkap, alamat, atau data kartu pembayaran. Pembayaran diproses sepenuhnya melalui QRIS.

2. Bagaimana Data Digunakan

Data yang kami kumpulkan digunakan untuk:

  • Memproses dan memverifikasi pembayaran sewa WiFi.
  • Mengirim kredensial WiFi dan struk transaksi ke WhatsApp-mu.
  • Menampilkan status pesanan melalui fitur Cek Status Pesanan.
  • Menjaga keamanan dan mencegah penyalahgunaan layanan.

3. Penyimpanan Data

Data transaksi disimpan pada layanan Firebase Firestore milik Google. Preferensi tampilan (tema terang/gelap) dan sesi admin disimpan secara lokal di browser kamu melalui localStorage. Kamu dapat menghapusnya kapan saja melalui pengaturan browser.

4. Pihak Ketiga

  • Firebase (Google) — penyimpanan data transaksi dan konfigurasi.
  • Google Fonts — font tampilan situs.
  • Discord — hanya digunakan pada halaman admin untuk autentikasi petugas.
  • Penyedia QRIS — memproses pembayaran sesuai skema QRIS nasional.

Kami tidak menjual atau membagikan data pribadimu kepada pihak lain untuk kepentingan komersial.

5. Retensi Data

Data transaksi disimpan untuk keperluan pembukuan dan verifikasi. Data lama dapat kami hapus secara berkala sesuai kebutuhan operasional.

6. Hak Kamu

Kamu dapat meminta penghapusan data transaksi dengan menghubungi admin melalui kanal WhatsApp resmi R STUDIO LABS, dengan menyertakan ID transaksi yang bersangkutan.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan diumumkan pada halaman ini dengan tanggal pembaruan terbaru.
